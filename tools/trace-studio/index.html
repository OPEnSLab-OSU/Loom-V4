    What these numbers mean

    Heap in use includes allocations from before tracing started, plus allocator rounding and overhead.

    Free heap is reusable space inside the allocator. Available RAM estimate adds the measured stack-to-heap gap. It reserves no future stack growth and is not a guarantee that one allocation of that size will succeed.

    Live captured bytes counts requested sizes of individually observed allocations still live at this event.

    Known present objects identifies observed containers and mux sensors. Their internal buffers are separate allocations.

    These are separate measurements. An object label does not add heap bytes, and a retained block alone is not proof of a leak.
